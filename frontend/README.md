# Karta frontend

A local, shell-only chat workspace. Svelte 5 runes, TypeScript, Vite and Tailwind; no SSR, daemon, account, or API key required.

## Quick start

Prerequisites: Node.js 22.12+ (or a compatible newer release), pnpm 9.15.9, and [Task](https://taskfile.dev/installation/).

```sh
cd frontend
pnpm install --frozen-lockfile
pnpm exec playwright install chromium
cd ..
task dev
```

Open http://127.0.0.1:9245. `WAILS_VITE_PORT=9250 task dev` changes the port. A busy port fails rather than silently selecting another.

```sh
task check:frontend  # svelte-check + static production build
task test:frontend   # local Chromium interaction and axe checks
task verify          # contracts, Go lint/tests/build, frontend checks/tests
```

On Linux, Chromium may need system libraries: `pnpm exec playwright install --with-deps chromium` installs them where authorized. See the root README for Go/tool prerequisites. To serve a production build, run `pnpm build && pnpm preview` from this directory.

## Code organization

Use small responsibility-focused components and colocated feature fixtures, following the useful organizational patterns in Open WebUI without copying its application or SvelteKit stack.

- `src/app/`: bootstrap and composition of navigation, chat, context, and overlays.
- `src/features/chat-stream/`: transcript, model preview, and composer.
- `src/features/settings/`: settings navigation and config-shaped drafts; fixtures remain here.
- `src/entities/session/`: typed sample sessions and page-lifetime runes state.
- `src/shared/ui/`: reusable overlay behavior, not feature logic.
- `src/shared/styles/`: primitive → semantic tokens and shared base styles.
- `src/shared/api/schema.d.ts`: generated by `task codegen`; never edit by hand.
- `tests/`: browser behavior, accessibility, and reproducible capture tooling.

Imports flow `app → features → entities → shared`; features never import one another. Use `$state`, `$derived`, `$effect`, and `$props`, not legacy reactivity. Add focused components when responsibility grows; do not split every field into an unnecessary abstraction. Keep docs near their subject and record architecture decisions in `docs/architecture/`.

## Shell behavior

Left navigation collapses to an icon rail on desktop. Below 768px it becomes a drawer; the right panel becomes a drawer below 1280px. The right panel starts closed. New Chat and sample conversation selection work in memory. Enter sends a deterministic mock reply, Shift+Enter inserts a newline, and IME composition does not send.

Settings includes Providers, MCP, Skills, Logging, and Advanced. Drafts survive section changes but closing the dialog discards them. Reset preview restores fixture values. Path hints are text, not file access. Provider/logging fields are illustrative proposals, not accepted daemon config. Never enter a real credential; the credential field previews an environment-variable name only.

Everything resets on reload, including theme. No browser storage, telemetry, external assets, HTTP/SSE integration, installation, or agent execution is present.
